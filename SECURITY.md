# Security Policy

## Supported versions

Security fixes, when available, are intended for the latest public stable version.

| Version                      | Security support |
| ---------------------------- | ---------------- |
| Latest public stable release | Supported        |
| Older releases and drafts    | Not guaranteed   |

## Reporting a vulnerability

Please report suspected vulnerabilities privately by emailing
[ray.mtgarchiver@gmail.com](mailto:ray.mtgarchiver@gmail.com) with a subject beginning with
`[Security]`.

Include:

- the affected application version;
- the affected component or feature;
- reproducible steps or a minimal proof of concept;
- the potential impact;
- whether the issue is already public; and
- any suggested mitigation.

Do not include real credentials, access tokens, private archives, personal information, or
third-party data in a report. Use sanitized examples.

Please allow reasonable time to investigate and prepare a fix before publicly disclosing an
unresolved vulnerability. Receipt of a report does not guarantee a particular response time,
resolution, reward, or public acknowledgment.

For ordinary bugs and feature requests, use [SUPPORT.md](SUPPORT.md).
